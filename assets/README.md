## 网站图标

- GitHub 标志：来自 [GitHub Primer Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg)，使用 MIT 许可，许可全文保存在 `icons/LICENSE-github.txt`。
- Bilibili 图标：来自 [Bilibili 网站图标](https://www.bilibili.com/favicon.ico)。
- 洛谷图标：来自[洛谷网站图标](https://fecdn.luogu.com.cn/favicon.ico)。
- AtCoder 图标：来自 [AtCoder 网站图标](https://img.atcoder.jp/assets/atcoder.png)。
- osu! 图标：来自 [osu! 官方网站图标](https://osu.ppy.sh/images/favicon/apple-touch-icon.png)，用于项目展示与兴趣爱好中的 osu! 账号入口。
- Codeforces 图标：来自 [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/codeforces.svg)，许可全文保存在 `icons/LICENSE-simple-icons.md`。这些网站标识仅用于标注对应的账号链接。
- 邮件图标：页面中的内联 SVG。

发布网页时保留整个 `assets/` 目录及上述许可文件。
