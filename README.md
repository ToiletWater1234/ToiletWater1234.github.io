## 网页版本

本仓库包含可直接用于 GitHub Pages 的静态个人主页，无需安装依赖或编译。

五个账号在网页中统一显示为可点击的网站图标，下方标注网站名称。

网页展示顺序为：个人基本信息 → 非游戏账号 → GitHub 项目 → 获奖经历 → OC 介绍 → 兴趣爱好。获奖经历按年级分组；游戏账号放在有独立标题的兴趣爱好区块中。基本信息直接展示在首页，不再设置重复的“关于我”区块。栏目和表情包不使用数字序号。

天梯赛只作为一项比赛展示，个人奖项嵌套在对应团队卡片内，默认收起，点击“个人奖项”可以展开或收起。个人证书图片位于团队奖项目录下的 `individual/` 子目录。

- `index.html`：首页结构与个人资料。
- `style.css`：颜色、字体和电脑 / 手机布局。
- `script.js`：复制邮箱与页脚年份。
- `favicon.svg`：浏览器标签页图标。
- `assets/`：绯棠立绘、表情包和网站图标，发布时需完整上传。
- `.nojekyll`：按静态文件发布。

### 本地查看与修改

双击 `index.html`，即可在浏览器中查看网页。修改个人资料时编辑 `index.html`；修改配色和排版时编辑 `style.css`。保存后刷新浏览器即可。`README.md` 是仓库说明，修改它不会同步修改 HTML 网页。

### 发布到 GitHub Pages

1. 将上述网页文件、完整的 `assets/` 文件夹及 `README.md` 上传到 `ToiletWater1234/ToiletWater1234.github.io` 仓库的根目录，保留文件之间的相对位置。
2. 在仓库 **Settings → Pages** 中，将 Source 设为 **Deploy from a branch**，选择保存这些文件的分支（通常为 `main`）及 **/ (root)**，然后点击 **Save**。
3. 等待部署成功后，访问 [个人主页](https://toiletwater1234.github.io/)。

后续可以继续补充课程项目、比赛经历、其他作品，以及更多音乐游戏账号。
